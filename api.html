Einleitung

Entwurf: SovereignMind wird derzeit ausschließlich als Demo zur Erprobung bereitgestellt. Die Nutzung im Produktivbetrieb ist nicht gestattet. Ob und wann offizielle Lizenzen angeboten werden, ist offen; ein Anspruch auf den Abschluss einer Lizenz besteht nicht.

Basis-URL

Die API läuft auf Ihrem eigenen Rechner. Standardmäßig ist sie unter http://<Rechner>:5043 erreichbar, auf dem Rechner selbst also unter http://localhost:5043. Ist HTTPS eingerichtet, erreichen Sie sie unter Ihrem Namen, z. B. https://chat.example.de. Alle Pfade dieser Seite hängen an dieser Adresse. Im Feld „Basis-URL der Beispiele“ links tragen Sie Ihre Adresse ein; die Codebeispiele übernehmen sie.

Ablauf: von der Registrierung bis zur Antwort mit Quellen

So gehören die Aufrufe zusammen (Reihenfolge auf einer frischen Installation):

  1. Zustand prüfen: GET /health und GET /api/system-status (mode, modelsMissing). Fehlen Modelle, zuerst laden; Fragen sind sonst nicht möglich.
  2. Registrieren (einmal): POST /api/tenant/register mit Lizenzdaten und Admin-Passwort.
  3. Als Admin anmelden (POST /api/auth/admin-login) und ein Mitglied für das Fachsystem anlegen (POST /api/admin/users). Eine Kategorie für Dokumente legt der Admin einmal an.
  4. Als Mitglied anmelden: POST /api/auth/login liefert das Zugriffstoken (accessToken).
  5. Dokument hochladen (POST /api/v1/documents) und warten, bis der Status Ready ist (GET /api/v1/documents). Neue Dokumente sind zunächst privat; der Admin kann sie für alle freigeben.
  6. Frage stellen: POST /api/v1/chat antwortet als Strom von data: {…}-Zeilen. Das letzte Ereignis ("type":"done") trägt die Quellen (citations).

Welche Installer enthalten die API?

Beide Installer (Voll und Minimal) enthalten die API unter /api derselben Adresse, zusammen mit der Weboberfläche.

Wer nur die API nutzt oder ein eigenes Frontend anbindet, schaltet die Weboberfläche ab (Linux sudo sovereignmind frontend off, Windows Tray-Menü „Weboberfläche“). Für Browser-Oberflächen auf einer anderen Adresse wird die Installation mit --cors (Linux) bzw. /CORS=https://app.example (Windows) eingerichtet.
