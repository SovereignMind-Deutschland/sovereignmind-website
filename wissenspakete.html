Fertige Wissensbestände für Ihre SovereignMind-Installation, zum Beispiel Gesetze und Verordnungen. Jedes Paket wird vor dem Import per Prüfsumme geprüft.

Paket in der App installieren

Als Admin öffnen Sie Admin > Wissenspakete > Paketkatalog, wählen das Paket und klicken auf „Installieren“. Signatur und Prüfsumme werden automatisch kontrolliert.

Datei manuell importieren (ohne Internet)

Laden Sie die .smpack-Datei hier herunter, übertragen Sie sie auf den Server und importieren Sie sie unter Admin > Wissenspakete per Dateiauswahl. Vergleichen Sie vorher die SHA-256-Prüfsumme aus der Paketkarte.

Hinweis: Der Katalog selbst kommt von dieser Seite. Die Paketdateien lädt Ihr Browser von GitHub (Release-Downloads); dabei wird Ihre IP-Adresse an GitHub übermittelt.
