Hosting

Diese Seite wird über GitHub Pages (GitHub Inc., USA) ausgeliefert. Beim Aufruf verarbeitet der Hosting-Anbieter technisch notwendige Daten wie die IP-Adresse in Server-Logfiles.

Keine Cookies, kein Tracking

Die Seite setzt keine Cookies, bindet keine externen Schriftarten und keine Analyse-Dienste ein.

Abfrage der aktuellen Version

Beim Aufruf kann Ihr Browser die neueste Release-Nummer über die GitHub-API (api.github.com) abrufen. Dabei wird Ihre IP-Adresse an GitHub übermittelt. Schlägt die Abfrage fehl, bleibt die Seite voll funktionsfähig.

Wissenspakete

Die Seite „Wissenspakete“ lädt nur die eigene Katalogdatei von dieser Domain. Klicken Sie auf einen Download, lädt Ihr Browser die Paketdatei von GitHub (Release-Downloads, github.com); dabei wird Ihre IP-Adresse an GitHub übermittelt.

Die Software selbst (Hinweise für Betreiber einer Installation)

SovereignMind läuft ausschließlich auf Ihrer eigenen Infrastruktur. Der Anbieter erhält über die Software keine Nutzer-, Dokument- oder Chatdaten; verantwortlich für deren Verarbeitung ist der Betreiber der Installation. Zwei Funktionen verarbeiten personenbezogene Angaben und sind daher für die Datenschutzerklärung des Betreibers relevant:

  • Lizenzbindung: Ein Lizenzschlüssel kann an die E-Mail-Adresse des Käufers, den Firmennamen und eine Zahlungsreferenz (Rechnungsnummer oder die letzten vier Stellen von Karte bzw. IBAN, nie die volle Nummer) gebunden sein. Im Schlüssel stehen diese Angaben nur als Hash; bei der Einrichtung gibt der Betreiber sie ein und die Software vergleicht die Hashes offline. Es findet keine Übermittlung an den Anbieter statt.
  • Geräte-Freigabe im Netzwerk: Beschränkt der Admin den Zugriff aus dem Netzwerk, speichert die Installation je Nutzer die freigegebenen IP-Adressen samt optionaler Bezeichnung und dem Admin, der sie angelegt hat. Abgelehnte Zugriffe erscheinen mit IP-Adresse und Nutzerkennung im Anwendungsprotokoll. Die optionale Suche nach Geräten im lokalen Netz liest die Nachbarschaftstabelle des Servers (IP- und MAC-Adressen) und speichert sie nicht.
