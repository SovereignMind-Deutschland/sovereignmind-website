Hosting

Diese Seite wird über GitHub Pages (GitHub Inc., USA) ausgeliefert. Beim Aufruf verarbeitet GitHub technisch notwendige Daten, insbesondere die IP-Adresse, in Server-Logfiles. Art und Dauer der Speicherung bestimmt GitHub.

Keine Cookies, keine Analyse, keine Fremdschriften

Die Seite setzt keine Cookies, bindet keine Analyse- oder Werbedienste ein und lädt keine Schriftarten von Fremdservern. Schrift und Demo-Video liegen auf derselben Domain.

Lokale Speicherung im Browser

Die Seiten speichern im localStorage Ihres Browsers nur Einstellungen, die Sie selbst vornehmen: die Farbwahl (hell/dunkel, Schlüssel sm-theme) und auf der Seite „API“ die gewählte Sprache und Basisadresse der Codebeispiele (sm-api-lang, sm-api-base). Diese Werte verlassen Ihr Gerät nicht. Sie können sie in den Browser-Einstellungen löschen.

Anzeige der aktuellen Version

Die Seiten „Download“ und „API“ laden die Datei assets/downloads.json von dieser Domain, um die aktuelle Versionsnummer anzuzeigen. Dabei werden keine Daten an Dritte übermittelt; es gelten die Angaben zum Hosting.

Downloads und Installationsbefehle

Ein Klick auf einen Download lädt eine Datei von GitHub (Release-Downloads, github.com); dabei wird Ihre IP-Adresse an GitHub übermittelt. Führen Sie den Installationsbefehl von der Download-Seite aus, ruft das Skript (install.ps1 bzw. install.sh) api.github.com und github.com auf, um die neueste Version zu ermitteln und zu laden. Dabei wird die IP-Adresse des ausführenden Rechners an GitHub übermittelt. Das geschieht erst, wenn Sie den Befehl ausführen. Die Installation selbst lädt die KI-Modelle von Hugging Face (huggingface.co) nach; auch dabei wird die IP-Adresse des Rechners übermittelt, es werden keine Nutzer- oder Dokumentdaten übertragen.

Wissenspakete

Die Seite „Wissenspakete“ lädt nur die eigene Katalogdatei von dieser Domain. Klicken Sie auf einen Download, lädt Ihr Browser die Paketdatei von GitHub; dabei wird Ihre IP-Adresse an GitHub übermittelt.

Kontakt

Wenn Sie uns per E-Mail schreiben (Link „Kontakt“), verarbeiten wir Ihre Adresse und den Inhalt Ihrer Nachricht, um Ihre Anfrage zu beantworten. Wir löschen die Nachricht, wenn die Anfrage erledigt ist und keine Aufbewahrungspflicht besteht. Die Seite hat kein Kontaktformular.

Die Software selbst (Hinweise für Betreiber einer Installation)

SovereignMind läuft ausschließlich auf Ihrer eigenen Infrastruktur. Der Anbieter erhält über die Software im Betrieb keine Nutzer-, Dokument- oder Chatdaten; verantwortlich für deren Verarbeitung ist der Betreiber der Installation. Der Anbieter hat keinen Fernzugriff auf Installationen. Zwei Funktionen verarbeiten personenbezogene Angaben und sind daher für die Datenschutzerklärung des Betreibers relevant:

  • Lizenzbindung: Ein Lizenzschlüssel kann an die E-Mail-Adresse des Käufers, den Firmennamen und eine Zahlungsreferenz (Rechnungsnummer oder die letzten vier Stellen von Karte bzw. IBAN, nie die volle Nummer) gebunden sein. Im Schlüssel stehen diese Angaben nur als Hash; bei der Einrichtung gibt der Betreiber sie ein und die Software vergleicht die Hashes offline. Es findet keine Übermittlung an den Anbieter statt.
  • Geräte-Freigabe im Netzwerk: Beschränkt der Admin den Zugriff aus dem Netzwerk, speichert die Installation je Nutzer die freigegebenen IP-Adressen samt optionaler Bezeichnung und dem Admin, der sie angelegt hat. Abgelehnte Zugriffe erscheinen mit IP-Adresse und Nutzerkennung im Anwendungsprotokoll. Die optionale Suche nach Geräten im lokalen Netz liest die Nachbarschaftstabelle des Servers (IP- und MAC-Adressen) und speichert sie nicht.
