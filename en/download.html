Install SovereignMind

Draft: SovereignMind is currently provided only as a demo for evaluation. Production use is not permitted. Whether and when official licenses will be offered is open; there is no entitlement to a license.

One command sets everything up, without Docker and without WSL. Whether demo or license, you decide only on the first launch of the app in the browser.

  • Freedemo without a license key
  • 24 hoursof uptime, then data is deleted
  • 1 seatreachable only on the machine itself
  • 8 GB VRAM · 16 GB RAMrecommended; about 3 GB installer plus models

More about the demo further down. The installer does not check the recommended hardware.

The script does the following in order:

  1. determines the latest version in the GitHub release and downloads the installation package (about 0.9 GB),
  2. compares each file with the checksum from SHA256SUMS.txt, unpacks the package and starts the installation,
  3. shows the end-user license agreement; you confirm it in the terminal, the script never agrees for you,
  4. then downloads the AI models (about 11 GB) from the internet.
Without administrator rights: what happens?

If PowerShell is not running as administrator, the script asks before the download whether it should continue in a new administrator window (y: the Windows security prompt appears immediately; n: only after the download). If the prompt is declined, the downloaded files stay in place; a new start does not download anything twice.

Read the script first

Without | iex the command only prints the script’s text. It is also available as a file: install.ps1.

Without the script: files from the release

On the release page, download all parts SovereignMind-Setup-Minimal-<Version>.zip.001 (and further .zip.NNN, if any), EULA.de.txt and SHA256SUMS.txt as well as the script install.ps1 into one folder. Compare the checksum of each part with the line in SHA256SUMS.txt, then start install.ps1 in a PowerShell as administrator with -SourceDir pointing to that folder. The script unpacks the package and asks for the end-user license agreement.

The installer contains the web interface, API and the AI server. If the network is missing or the download is aborted, SovereignMind is still installed: the admin sees the notice “Load now” in the admin area.

Requirements

  • Windows 10 (1809), Windows 11 or Server 2019+ (x64)
  • Administrator rights
  • Space for the installer (about 3 GB) and the models (about 11 GB)
  • Recommended: 8 GB VRAM and 16 GB RAM. Without a GPU everything runs on the CPU, noticeably slower.
More notes on hardware and license
  • CPU speech output needs about 8 GB of additional RAM. A Mac with unified memory is untested.
  • Nothing else is needed for the demo. You need a license key (token) and the details it is bound to (email address, possibly company name and payment reference) only if the provider has expressly issued you one.
  • Optional: the hardware agent (Windows service for real CPU/RAM/GPU values in the dashboard) can be selected as a task in the setup.

Using it afterwards: the tray app “SovereignMind Control” in the taskbar notification area starts and stops all services, shows the status and opens the web interface.

For advanced users

One-liner with options (SM_SETUP_ARGS, SM_VERSION)

Pass setup options before the command in SM_SETUP_ARGS, for example for your own interface without the web interface. SM_VERSION selects a specific version.

Speech output on the graphics card

Speech output runs on the CPU by default. To use the graphics card, choose “Voice” in the admin area; the admin downloads GPU support (PyTorch, about 4 GB on NVIDIA, about 5 GB on AMD) there when needed. The admin also loads the larger 14B chat model themselves (admin area, local models).

Your own front end or API only

The web interface is on by default. To turn it off, clear “Serve web interface” in the setup (silent: /FRONTEND=off) or later in the tray menu. SovereignMind then provides only the API; the setup shows the API address and places the endpoint documentation in the Start menu.

  • /CORS=https://app.example allows browser interfaces on a different address.
  • /LICENSEEMAIL=… /LICENSETOKEN=… /ADMINPASSWORD=… creates the tenant and admin silently.

The script does the following in order:

  • sudo rights

More notes on hardware, distributions and license
  • The RPM family (Fedora, Rocky Linux) is not yet tested; the bundle may work there but is not approved.
  • The AI server (llama.cpp) uses NVIDIA, AMD and Intel GPUs via Vulkan, otherwise the CPU. An earlier Ollama installation of the package is taken over.
  • The installer does not check the recommended hardware. CPU speech output needs about 8 GB of additional RAM; its GPU support is downloaded in the admin area when needed. A Mac with unified memory is untested.
  • The chat model is chosen automatically by available VRAM and can be changed in the admin area under “AI settings”.
  • Nothing else is needed for the demo. You need a license key (token) and the details it is bound to (email address, possibly company name and payment reference) only if the provider has expressly issued you one.

Day-to-day operation

After installation SovereignMind runs as a background service and starts with the machine. Nobody needs system knowledge for start, stop and status: on Windows the tray app handles it, on Linux a single command.

Windows: tray app
“SovereignMind Control” sits in the taskbar notification area. It shows whether everything is running, starts and stops the services and opens the web interface.
Linux: sovereignmind
One command for open, status, start, stop, restart, logs, lan, https and backup. Commands that need privileges call sudo themselves.
HTTPS proxy
The installer includes an HTTPS proxy: internal CA, Let's Encrypt or a supplied wildcard certificate without a browser warning. Chat and admin area run under their own names, and the demo starts there too.
API for line-of-business systems
Every installation includes an interface for connecting your own front ends and line-of-business systems. You can read up on all endpoints, sign-in, errors and code examples without installing anything.

Demo (no license, 24 hours)

To try it out you need no separate installer. After installation the app asks on first launch: “Start demo” or “Set up with license”. The demo runs without a license key, is the same software with fixed limits, and deletes itself:

  • 24 hours: Service uptime counts; after 24 hours at the latest it is over. After that all data is deleted, including what you created in the demo. Setting the clock back does not extend the period. A new demo can be started afterwards.
  • Only at the configured addresses: The software enforces that the demo is reachable only on the machine itself (http://localhost:5043) or under the name you set up during installation for HTTPS (see below) or network access. At any other address it rejects the demo.
  • Credentials: admin with password sovereignmind, user test@sovereignmind.de with password sovereignmind. Both are also shown on the sign-in page.
  • Limited: one seat (no further users), passwords and license cannot be changed, connectors locked, at most 50 documents and 200 MB, no backups.
  • Unlock with a key: If the provider has expressly issued you a license key, it unlocks the demo installation. You choose whether the demo data is kept or deleted. A second installation or an uninstall is not needed.
  • Same size and same requirements as above (the models are downloaded).

Installation and download as above under Windows or Linux. You confirm the end-user license agreement twice: in the installer and in the app, when starting the demo or during setup.

End-user license agreement

The end-user license agreement (EULA) must be confirmed during installation. The Windows script install.ps1 shows it before installing and asks in the terminal (or in advance with -AcceptEula); the Linux bundle asks in a configuration dialog (or in advance with --accept-eula). Without agreement, nothing is installed. The EULA is currently only a draft and has not yet been legally reviewed; the same notice is at the top of this page and in the app.

After installation

  1. Open the app: http://localhost:5043 (the port can be chosen during installation) or, if HTTPS is set up, at https://chat.example.de (your name)
  2. On first launch the app shows a welcome page: “Start demo” (no key, 24 hours) or “Set up with license” (license key, company and admin password; activation works offline).
  3. Everything runs as a background service and starts with the machine. Status and control: tray app (Windows) or sovereignmind status (Linux).

HTTPS on the network

The installer includes an HTTPS proxy (Caddy). On Windows you set it up on the “HTTPS” page of the setup, on Linux with sudo sovereignmind https chat.example.de <mode>. Chat (chat.…) and admin area (admin.…) are two separate apps with their own names behind the same backend. The demo also starts under these names. For other devices on the network, LAN access must be on (sovereignmind lan on); it is off by default. In addition, the admin can restrict access under “Network & devices” to approved pairs of user and IP address. If you lock yourself out, sovereignmind lan open on the server restores open access.

Checksums and Windows warning

Each file of the current version has a SHA-256 checksum. The one-liners check it themselves; for a manual download, compare the file’s checksum with the line in SHA256SUMS.txt on the release page or with this table.

FileSHA-256

The checksums of the current version are in SHA256SUMS.txt on the release page.

Signature of the checksums (minisign): Checksums detect damaged downloads, but not a swapped release: whoever swaps the release can also swap SHA256SUMS.txt. That is why the signature SHA256SUMS.txt.minisig sits next to it. It is created offline with our private key; the one-liner scripts and this page contain the public key, so it comes from a different place than the release.

The one-liners verify the signature themselves if minisign is installed (Linux: sudo apt install minisign, Windows: winget install jedisct1.minisign). Without minisign they warn and only check the checksums; with SM_REQUIRE_SIGNATURE=1 they then abort. An invalid signature always aborts the installation.

The signature is being introduced. As long as no public key is shown here, the releases are not yet signed and the one-liners only check the checksums.

Windows warning (SmartScreen): The installation package and install.ps1 are not signed with a certificate. Windows may therefore show “Windows protected your PC”. Check the file’s checksum; if it matches, choose “More info” and then “Run anyway”. Setup remains an administration task and needs administrator rights anyway.

License and knowledge packages

The provider issues license keys only expressly; whether and when official licenses will be offered is open. A key is bound to an email address and may additionally be bound to company name and payment reference (invoice number or last four digits of card or IBAN); you enter these details during setup. They are stored in the key only as a hash. Please do not pass the key on: after five wrong entries per hour, redemption is temporarily blocked. The admin downloads knowledge packages directly in the app under “Knowledge packages”. Packages with an extra feature require a matching license.

Update and backup

Update: run the new version of the installer: run the one-liner again (it takes the latest version) or start the new setup or bundle by hand. Data, keys and license are kept; a database dump is created before the update.

Backup: The daily backup runs automatically. Recovery and uninstall are described in the operator manual, which is delivered with provider support.
