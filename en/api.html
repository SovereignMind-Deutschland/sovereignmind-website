Introduction

Draft: SovereignMind is currently provided only as a demo for evaluation. Production use is not permitted. Whether and when official licenses will be offered is open; there is no entitlement to a license.

Base URL

The API runs on your own machine. By default it is reachable at http://<machine>:5043, so on the machine itself at http://localhost:5043. If HTTPS is set up, you reach it under your own name, e.g. https://chat.example.de. All paths on this page hang off this address. Enter your address in the field “Base URL for the examples” on the left; the code examples use it.

Flow: from registration to an answer with sources

How the calls fit together (order on a fresh installation):

  1. Check the state: GET /health and GET /api/system-status (mode, modelsMissing). If models are missing, load them first; questions are not possible otherwise.
  2. Register (once): POST /api/tenant/register with license data and admin password.
  3. Sign in as admin (POST /api/auth/admin-login) and create a member for the line-of-business system (POST /api/admin/users). The admin creates a document category once.
  4. Sign in as a member: POST /api/auth/login returns the access token (accessToken).
  5. Upload a document (POST /api/v1/documents) and wait until the status is Ready (GET /api/v1/documents). New documents are private at first; the admin can share them with everyone.
  6. Ask a question: POST /api/v1/chat answers as a stream of data: {…} lines. The last event ("type":"done") carries the sources (citations).

Which installers include the API?

Both installers (Full and Minimal) include the API at /api on the same address, together with the web interface.

If you only use the API or connect your own front end, turn off the web interface (Linux sudo sovereignmind frontend off, Windows tray menu “Web interface”). For browser interfaces on a different address, the installation is set up with --cors (Linux) or /CORS=https://app.example (Windows).
